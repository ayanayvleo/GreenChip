# GreenChip

GreenChip is an FPGA-based intelligent power and thermal-management system.

## Project Goals

- Monitor hardware activity
- Detect idle and high-load conditions
- Track estimated energy consumption
- Monitor temperature data
- Control cooling through PWM
- Transition between operating power states
- Provide system status through UART and LEDs

## Repository Structure

- `docs` — Engineering documentation
- `rtl` — Synthesizable SystemVerilog modules
- `tb` — SystemVerilog testbenches
- `constraints` — FPGA timing and pin constraints
- `sim` — Simulation outputs, logs, and screenshots
- `reports` — Timing, utilization, verification, and debug reports
- `images` — Architecture diagrams and waveform images
